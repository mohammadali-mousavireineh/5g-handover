# Related-work positioning

The manuscript positions the repository against four literature groups: (1) standards-driven and adaptive TTT/hysteresis control, (2) reinforcement-learning handover decision policies, (3) supervised temporal prediction and proactive preparation, and (4) public real-network datasets and O-RAN event-log validation. See `references.bib` for the verified bibliography.

The central distinction is methodological: this project keeps target construction and splitting fixed within each seed and compares representation stages (raw windows, engineered dynamics, ANOVA, PCA, direct deep models, extracted deep features, and combined deep features) across proxy and event-log label sources.
