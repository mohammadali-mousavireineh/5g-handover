# Confirmatory D3 paper summary

`paper_table_confirmatory_d3_rounded.csv` reproduces the rounded values shown in Table 5 of the manuscript. It is a compact publication-level summary, not a substitute for the runner-generated per-seed outputs.

The exact validation-selected metrics reported in the manuscript text are:

- precision = 0.3988 ± 0.0354
- recall = 0.6587 ± 0.0150
- F1 = 0.4959 ± 0.0262
- average precision = 0.4231 ± 0.0357
- MCC = 0.5033 ± 0.0221
- specificity = 0.9855 ± 0.0022
- false positives per 1,000 negative windows = 14.46 ± 2.23
- event-level recall = 0.8811 ± 0.0160
- mean positive prevalence = 1.42%

The detailed files `confirmatory_natural_test_all_seeds.csv`, `confirmatory_natural_test_aggregate.csv`, and `validation_selected_model_test_results.csv` are generated by `src/d3_confirmatory_natural_test_runner.py` when the public D3 dataset is run. Large generated predictions and trained models are not committed.
