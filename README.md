# 5G Handover Prediction using Deep Learning

This repository contains a research-oriented Python implementation for **5G handover prediction** using real drive-test measurement data and deep learning models.

The main goal is to study how radio signal measurements, especially **RSRP** values, can be used to predict future signal behavior and support more intelligent handover decisions in mobile networks.

This work is part of a broader research direction on **AI-based mobility management**, **predictive handover**, and future **5G/6G service continuity**.

---

## Project Overview

Handover is a critical process in cellular networks. When a user equipment moves between cells, the network must decide when and where to transfer the connection. Poor handover decisions can cause:

* Radio link failure
* Ping-pong handovers
* Packet loss
* Increased latency
* Lower Quality of Service and Quality of Experience

This project explores the use of deep learning models to predict radio signal behavior and prepare the ground for smarter handover prediction.

---

## Current Scope

The current version focuses on:

* Processing real drive-test measurement data
* Extracting RSRP time-series values
* Detecting handover events based on PCI changes
* Training deep learning models for RSRP prediction
* Preparing data for future handover classification
* Comparing sequence-based models such as LSTM, GRU, and TCN

## Methodology

The general workflow is:

1. Load real drive-test measurement files.
2. Select relevant radio features such as RSRP and PCI.
3. Detect handover events by observing PCI changes.
4. Normalize RSRP values using MinMax scaling.
5. Create time-window sequences for deep learning models.
6. Train recurrent or temporal models to predict future RSRP values.
7. Evaluate prediction performance using error metrics such as MAE.
8. Use predicted signal behavior as a basis for future handover classification.

---

## Models Used

### LSTM

Long Short-Term Memory networks are used to learn temporal dependencies in RSRP sequences.

### GRU

Gated Recurrent Unit models are used as a lighter alternative to LSTM while still capturing time-series patterns.

### TCN

Temporal Convolutional Networks are used to model sequential signal behavior using convolution-based temporal learning.

```bash

```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

```bash
.venv\Scripts\activate
```

```bash
source .venv/bin/activate
```

Install dependencies:


## How to Run

Run one of the model scripts from the project root:

```bash
python scripts/anatel_lstm_rsrp.py
```

or:

```bash
python scripts/anatel_gru_rsrp.py
```

or:

```bash
python scripts/anatel_tcn_rsrp.py
```

The scripts load measurement files from the `real_data/` directory, train the selected model, and generate RSRP prediction results.

## Dataset

The repository includes drive-test measurement CSV files in the `real_data/` directory.

These files are used to extract radio signal indicators such as:

* RSRP
* PCI
* Handover trigger labels

The handover trigger label is generated by detecting changes in the serving cell PCI.
