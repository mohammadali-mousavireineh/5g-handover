# Enhanced 5G Handover Prediction over Real-Network RSRP Traces

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Reproducible](https://img.shields.io/badge/Reproducibility-code%20%2B%20data%20included-brightgreen)](#quick-start)

This repository contains the source code, processed datasets, trained temporal-model artifacts, figures, and manuscript files for the paper:

> **Enhanced 5G Handover Prediction over Real-Network RSRP Traces Using Lightweight Temporal Neural Representations**  
> **Mohammadali Mousavireineh**, **Astra Mousavireineh**  
> Contact: <mousavireineh@gmail.com>

The study compares handover classification performance when the predicted-RSRP temporal windows are generated by three sequence models:

- **LSTM** as the baseline recurrent representation.
- **GRU** as a lighter recurrent alternative with fewer gates.
- **TCN** as a temporal-convolutional representation that captures local and longer-range signal patterns with causal/dilated convolutions.

The main contribution of this repository is a clean, reproducible, GitHub-ready pipeline for evaluating these representations under a stricter held-out test protocol on processed ANATEL real-network RSRP traces.

## Quick start

Create and activate a virtual environment:

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate   # Linux/macOS
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the default strict held-out evaluation:

```bash
python anatel_grid_compare.py
```

Run a larger grid-search experiment:

```bash
python anatel_grid_compare.py --cv 5 --full-grid
```

Run with leakage-safe SMOTE applied only inside training/CV folds:

```bash
python anatel_grid_compare.py --use-smote --cv 5 --full-grid
```

## Current best results

The default repository results use a stratified train/test split with untouched held-out test data. Grid search is performed only on the training set. The table below reports the best classifier for each temporal feature generator.

| Feature model | Best classifier | Accuracy | Balanced accuracy | Precision | Recall | F1-score | ROC-AUC |
|---|---:|---:|---:|---:|---:|---:|---:|
| TCN | SVM_RBF | 0.6810 | 0.6540 | 0.3289 | 0.6098 | 0.4274 | 0.6938 |
| LSTM | SVM_RBF | 0.6762 | 0.6510 | 0.3247 | 0.6098 | 0.4237 | 0.7050 |
| GRU | SVM_RBF | 0.6714 | 0.6296 | 0.3108 | 0.5610 | 0.4000 | 0.7004 |

The key finding is that the **TCN-based representation achieves the best F1-score** under the stricter held-out test protocol, while the LSTM and GRU representations remain competitive. Because the positive handover class is the minority class, this repository emphasizes **F1-score, recall, balanced accuracy, ROC-AUC, and confusion matrices** rather than accuracy alone.

## Method summary

1. Load the processed ANATEL feature bases for LSTM, GRU, and TCN.
2. Use the first 50 columns as predicted-RSRP temporal features.
3. Use the final column as the binary handover-trigger label.
4. Train multiple classifiers with grid search:
   - SVM with RBF kernel
   - Random Forest
   - KNN
   - Logistic Regression
   - optional Gradient Boosting with `--full-grid`
5. Evaluate the selected model on an untouched stratified held-out test set.
6. Report accuracy, balanced accuracy, precision, recall, F1-score, ROC-AUC, and confusion matrices.

## Reproducibility notes

The processed feature bases are included in `data/processed/`, so the main comparison can be reproduced immediately. The legacy scripts used to build the feature bases are retained in `experiments/legacy_feature_generation/`. Raw drive-test CSV files are not included; place them in the expected `real_data/` directory before running the legacy feature-generation scripts.
